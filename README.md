# Automated Railway Level-Crossing Control System (ARLCCS)
## Software Verification Lab

This repository contains the software verification artifacts for the **Automated Railway Level-Crossing Control System (ARLCCS)**. As a Software Verification Team, our objective is to analyze system requirements, define safety constraints, formalize them into logic expressions, and evaluate realistic failure scenarios.

---

## Repository Contents

* [Task 1: Identified Constraints](./Task1_Constraints.md) — 10 core safety and operational constraints.
* [Task 2: Formalized Constraints](./Task2_Formalization.md) — Mathematical and logical propositions using propositional logic.
* [Task 3: Constraint Violations](./Task3_Violations.md) — Realistic failure scenarios and verification analysis for each constraint.

## Objectives
1. **Identify** non-ambiguous rules restricting system behavior.
2. **Formalize** rules using logical operators ($\land$, $\lor$, $\neg$, $\to$).
3. **Analyze** failure states where safety invariants are breached.
